About

Movies, shows, files and passwords, running at home. Nothing is open to the internet.

It works on the home Wi-Fi, or anywhere else with NetBird on. Then tvserver.homes opens Home instead of this page.

Leave NetBird on. It only carries server traffic.

Get connected
  1. Ask for an invite

    ghazi sends you a NetBird invitation and a TV Server login.

  2. Install NetBird and sign in

    Use the email and password from the invitation. Steps for each device are below.

  3. Open tvserver.homes

    With NetBird on, it opens Home. Sign in with your TV Server login.

Install NetBird
  1. Install NetBird P2P VPN from the App Store.
  2. Open NetBird and tap the big connect button.
  3. When iPhone asks to add VPN configurations, tap Allow. You may need Face ID or your passcode.
  4. A sign-in page opens. Sign in with the email and password from your NetBird invitation.
  5. Go back to the NetBird app. It should say Connected.

You can also switch it on and off in iPhone Settings > VPN.

  1. Install NetBird from Google Play.
  2. Open it. If it says it is using the default server, tap Continue.
  3. Tap the NetBird logo button, then tap OK when Android asks to allow a VPN connection.
  4. A sign-in page opens in your browser. Sign in with the email and password from your NetBird invitation, then close the browser.
  5. The app should say Connected.

Optional: keep it always on. In Android Settings > Network & internet > VPN, tap the gear next to NetBird and turn on Always-on VPN. Menu names differ between brands, so search Settings for "VPN".

  1. Download the installer from the NetBird macOS page and install it. Pick Apple Silicon for most Macs from 2021 on, Intel for older ones.
  2. Open NetBird from Applications. If it asks which server to use, choose NetBird Cloud.
  3. If your Mac asks to allow a VPN configuration or a system extension, click Allow. On some Macs this is under System Settings > Privacy & Security.
  4. Click the NetBird icon in the menu bar at the top of the screen, then Connect.
